    Sessions

    Work through them in order; later sessions assume the water-quality parameters measured in earlier ones. Progress is stored in this browser only.

      How to use the lab

      1 · Read the brief

      Objectives, theory and procedure come first. The equations on each page are the ones the calculation panel uses, so you can check every number by hand.

      2 · Operate the apparatus

      Sliders and buttons change real operating variables — dose, flow rate, particle size, contact time. The readouts respond continuously, not at fixed presets.

      3 · Record readings

      Use Record reading to append a row to the observation sheet. Rows persist while the page is open and can be exported as CSV.

      4 · Complete the session

      Answer the review questions, then mark the session complete. The sidebar keeps a tally so you can leave and return.

      Report

      Every session page prints cleanly to PDF: browser menu → Print. Simulation panels are dropped from the print layout and answer blocks are expanded.

      Data

      Observation sheets export to CSV for use in a spreadsheet or the analysis section of your report.
